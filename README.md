# iLoveResume

## Objetivos

O **iLoveResume** é uma aplicação web desenvolvida com React e Vite para a criação, edição e personalização de currículos profissionais otimizados para sistemas ATS (*Applicant Tracking System*). 

A plataforma foi projetada para oferecer uma experiência simples e intuitiva, permitindo que candidatos preencham suas informações profissionais e gerem currículos bem estruturados e prontos para serem exportados.

---

## Como Rodar o Projeto Localmente

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) (versão 18 ou superior) e o **npm** instalados em sua máquina.

### Passos

1. **Acessar o diretório do projeto**:
   ```bash
   cd iLoveResume
   ```

2. **Instalar as dependências**:
   ```bash
   npm install
   ```

3. **Executar o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. **Acessar a aplicação**:
   Abra o seu navegador e acesse a URL informada no terminal (geralmente `http://localhost:5173`).
